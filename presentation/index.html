Your family's privacy is our highest priority — zero compromises

🔑

JWT Authentication

Secure, stateless JSON Web Tokens ensure only verified family members can access the app.

📱

Single-Device Sessions

Login on a new device instantly logs out all other sessions — no shared accounts.

🔒

bcrypt Password Hashing

Passwords are never stored in plain text — industry-standard salted hashing protects every account.

👑

Role-Based Access

Parents, children, grandparents — each role has appropriate permissions and admin controls.
