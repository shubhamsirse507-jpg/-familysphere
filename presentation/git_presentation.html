Git Command Reference: Local Setup & Staging

Fundamental commands to set up repositories and track files locally

⚙️ Setup & Initialization

git init

Initialize a brand new local Git repository in the current directory.

git init
git clone

Clone/download an existing remote repository from GitHub locally.

git clone https://github.com/shubhamsirse507-jpg/-familysphere.git
git config

Set user parameters such as commit author name and email address.

git config --global user.name "shubhamsirse507-jpg"

📂 Tracking & Staging Changes

git status

Show the state of the working directory and files (tracked, untracked, staged).

git status
git add

Stage specific files or all modified files to prepare them for commit.

git add .
git commit

Create a checkpoint log and save staged files to local repository history.

git commit -m "feat: add real-time features"

Git Command Reference: Syncing & Branching

Advanced commands for branching, team collaboration, remote updates, and histories

📡 Syncing with GitHub Remotes

git pull

Fetch and integrate latest changes from the remote GitHub branch.

git pull origin main
git push

Upload committed local branch files to the remote repository.

git push origin main
git remote -v

Display connection URL mappings for remote repositories.

git remote -v

🌿 Branches, History & Utilities

git checkout -b

Create a new branch and switch the workspace active folder to it.

git checkout -b feature/chat-room
git stash

Temporarily shelve / hide modified uncommitted files to clear your branch.

git stash && git stash pop
git log --oneline

Show clean, simplified history of commits in single lines.

git log --oneline -n 5
